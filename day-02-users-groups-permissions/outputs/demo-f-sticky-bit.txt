Mode: 1777 (drwxrwxrwt)  Sticky bit indicator: drwxrwxrwt

Explanation: When the sticky bit (1000 / 't') is set on a world-writable directory (e.g. /tmp),
unprivileged users can create files, but can ONLY delete or rename files they personally own
or if they own the parent directory (or root).
