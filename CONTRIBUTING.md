# Contributing

Thank you for your interest in improving this educational project!

## Reporting Issues and Suggestions
- Corrections, clarifications, and bug reports for code or lab instructions are very welcome. Please open an issue detailing what you observed versus what was expected.
- Keep discussions respectful, focused, and educational.

## Security and Privacy Guidelines
- **No secrets in issues or pull requests:** Never post API keys, cloud credentials, tokens, SSH keys, private IP addresses, or sensitive local file paths.
- If you notice any accidentally exposed sensitive information or personal identifiers in any output file, please open an issue immediately so it can be redacted.
